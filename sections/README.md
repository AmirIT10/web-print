# Sections Design Workspace

این فولدر محل نگهداری Design Spec و دستورالعمل‌های پیاده‌سازی بخش‌های تأییدشده پروژه است.

## Sections
- `home/` — Home Page
- `product-detail/` — Product Detail Page

## Workflow
1. PM PRD را تأیید می‌کند.
2. Designer IA، Wireframe و UI Spec را آماده می‌کند.
3. README هر Section تکمیل می‌شود.
4. PM Design Gate را تأیید می‌کند.
5. Developer بر اساس README پیاده‌سازی می‌کند.
6. Designer Design QA انجام می‌دهد.
