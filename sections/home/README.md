# Home Page

## وضعیت
Design phase — PRD approved by PM.

## هدف
ساخت اولین تجربه کاربر و هدایت او از معرفی کسب‌وکار به دسته‌بندی و سپس Product Detail.

## ساختار پیشنهادی
- `HomePage`
- `Header`
- `HeroSection`
- `CategorySection`
- `FeaturedProductsSection`
- `ServicesSection`
- `PrimaryCTA`
- `Footer`

## قرارداد داده
در این فاز داده‌ها Mock/Static هستند. ساختار داده باید برای جایگزینی با Vendure آماده باشد.

## حالت‌ها
تمام Sectionهای داده‌محور باید `default`, `loading`, `empty`, `error` را پوشش دهند.

## Responsive
- Mobile: کمتر از 768px
- Tablet: 768 تا 1024px
- Desktop: بیشتر از 1024px

## Navigation
تمام لینک‌های داخلی باید از سیستم navigation پروژه استفاده کنند و مسیر Home → Category/Product → Product Detail را حفظ کنند.

## Design QA
پیاده‌سازی باید مطابق Design Spec نهایی Designer بررسی شود. مقادیر رنگ، typography، spacing و interaction در README نهایی Design تکمیل خواهند شد.
